# VocabCraft

## AI-powered Personal Knowledge Memory System

Turn your daily questions into long-term knowledge.

---

## Why VocabCraft?

Most learning systems start with textbooks.

But real learning starts with problems.

Every day, we encounter:

- unfamiliar English words
- technical documents
- professional concepts
- communication barriers

Usually we search for an answer and forget it later.

VocabCraft transforms these temporary questions into personal knowledge assets.
